# 현재 구현 0.8

현재 실행 안내는 README 상단과 spatial-v08.md를 따른다. 기본은 세로 720×1280 클릭/탭 조작이다.

정상 영업: 손님 반복 도착, 객실 두 개 지정 배정, 주문·준비·운반·전달, 퇴실·청소, 직원 고용·서빙 위임, 임금·임대료·세금 징수.

비밀 작업: 입구로 접근 후 지하 이동, 도구를 이용한 직접 굴착, 내구도·조용한 작업, 직원 청취·확인·기억, 인물 선택·제압·운반·회복, 구금칸 설치·유지비·석방·탈출, 의뢰 성공/보호/실패, 목격·출구 신고·경비 방문·제한 수색·뇌물·벌금.

공간: 로우폴리 사선 3D, 넓힌 1층과 마당, 실제 경사 계단과 걸을 수 있는 2층 복도. 2층에서 1층 손님·직원과 홀을 함께 본다. 지하는 별도 화면이며 연속 바닥·외곽 흙벽으로 그린다. 굴착 규칙은 격자다.

저장: 운영·인물·굴착·의뢰·구금·조사·2층 위치와 진행 중 이동을 수동 저장한다. Web 저장은 브라우저별이다.

검증: 133개 시뮬레이션 + 37개 실제 포인터/터치 = 170개. 실제 Godot 720×1280 렌더링 확인. Android/iPhone 실기기 성능·안전 영역은 별도 검증이 필요하다.

## 남은 범위

객실과 직원 영업은 아직 1층이다. 2층 객실 배치·NPC 일상 계단 이동·난간 너머 AI 시야·도청, 지하와 지상 동시 단면 보기, 손님 간 다툼·세력 임대·자유 건축 전체, 전투·사망·시신·음식 효과·장기 캠페인·완성 인물 애니메이션·역사 지역 확정은 미구현이다.

모든 금액·기간은 시제품 조정값이다. 완성 게임의 재미·품질 통과를 의미하지 않는다. 과거 0.3~0.7 문서는 제작 이력이다.
