# 현재 구현 0.3
P1 운영 연결과 P2 지하·저장의 기본을 구현했다.
손님 반복 도착 → 접수대에서 지정 객실 배정 → 격자 경로로 입실 → 식사 주문 → 주인/직원의 시간제 준비·운반·전달 → 결제 → 퇴실·청소의 흐름이다.
직원 고용/서빙 위임, 임금/임대료/징수 방문, 지하 격자 굴착, 일시정지/3배속, 수동 저장/불러오기, 한글 UI, 임시 인물의 다리 움직임을 추가했다.
캐릭터·세계 데이터의 원본은 simulation.gd다. main.gd는 모델/입력/UI/화면을 담당하고 tests.gd는 반복 가능한 검증을 한다.
모델 화면 경계에서 장애물을 만들고 같은 격자를 주인과 NPC가 사용한다. 인물끼리의 밀기·군중 회피는 아직 없다.

## 미완성
기절/끌기/음식 효과, 비밀 정보/목격 판단, 범죄·조사관 AI, 세력 계약, 직원 성향·휴식/출입 권한, 객실 변경, 자유 건축, 다층 지하, 완성 인물/소리, 정확한 역사 지역은 아직 없다.
이번 소음 수치는 굴착 시 발생/감쇠하는 기초 신호이며 NPC 청취/수색이나 실제 음향과 연결되지는 않았다. 손님의 짧은 성격 설명도 현재는 접수 정보이며 행동 성향 시스템 완성을 뜻하지 않는다.
지상은 기존 2객실이다. 지하는 시작 3×3칸, 현재 굴착 허용 범위는 25×17칸으로 제한하며 최종 상한이 아니다. 지상보다 넓게 확장 가능한지 검증하는 단계다.
식사 메뉴는 1종이고 주인 또는 고용 직원이 접수대에서 준비한다. 접수/객실 결정은 주인이 하고 직원은 조리·서빙만 위임받는다.
누적 부채는 기록만 하며 압류/협상은 미구현이다. 모든 금액·기간은 시제품 조정값이다.

## 다음 구현
실행 피드백 후 손님 간 접촉/시야/소리를 이용한 사건 한 건과 직접 행동(기절·끌기)을 공통 엔티티에 연결한다. 새 미술이나 세력을 대량 추가하지 않는다.
