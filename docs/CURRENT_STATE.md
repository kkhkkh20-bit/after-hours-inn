# 현재 구현 0.9

현재 실행 기준은 README 상단과 landscape-v09.md다. 기본 1600×900 가로 화면, 클릭/탭 조작, 주인을 따라가지 않는 전체 보기다.

공간: 2층 다락/복도와 실제 경사 계단, 1층 홀과 두 객실, 이동 가능한 오른쪽 마당, 표시 높이 -4.2의 연결된 지하. 전체 보기에서 동시에 표시한다. 주인 따라가기·보기 필터·화면 끌기·확대/축소도 가능하다.

지하: 새 시작 55칸의 방·통로·창고, 거친 연속 흙벽과 바닥, 직접 접근 후 굴착, 도구 내구도, 조용한 삽/빠른 곡괭이, 가로 ±22/세로 ±12 확장. 기존 저장 지형을 유지한다. 등불·입구 덮개 조작, 빛에 따른 NPC 식별과 통로/덮개에 따른 소리 감쇠를 연결했다.

영업: 반복 손님, 객실 두 개 지정 배정, 주문·준비·운반·전달·퇴실·청소, 직원 고용·서빙 위임, 임금·임대료·세금 징수.

비밀 행동: 직원 청취·확인·기억, 제압·운반·회복, 구금칸 설치·유지비·석방·탈출, 의뢰 성공/보호/실패, 목격·출구 신고, 마당 문부터 경비 접근·제한 수색·뇌물·벌금.

저장: 운영·인물·굴착·의뢰·구금·조사·2층 위치·진행 중 이동·등불·덮개 상태를 저장한다. Web 저장은 브라우저별이다.

검증: 146개 시뮬레이션 + 45개 실제 포인터/터치 = 191개 통과. 실제 Godot 1600×900 렌더링 확인. Android/iPhone 실기기 성능·안전 영역은 별도 확인이 남아 있다.

남은 범위: 숙박 운영은 1층 두 객실이며 2층 다락은 걸어볼 수 있는 공간 시제품이다. 2층 투숙/서빙 AI·층간 도청·시야·일반 문 개폐, 사다리 승강 애니메이션, 손님 간 사건·세력 임대·자유 건축 전체, 전투·사망·시신·음식 효과·장기 캠페인·완성 인물 동작·재질·음악·역사 지역 확정은 후속이다. 굴착은 내부 격자 완료 단위이며 자유 곡면 조각은 아니다. 빛·소리는 거리·통로·입구 상태 기반 규칙이다.

금액·기간·현재 미술은 시제품 기준이다. 과거 0.3~0.8 문서는 제작 이력이다.
