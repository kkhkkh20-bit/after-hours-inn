# 1.7.9 편의성 조사와 적용 계획

## 공식 자료와 적용 판단
- Stardew Valley 개발자 모바일 안내(2019): 언제든 저장, 핀치 확대, 모바일 조작 선택을 제시한다. 현재 버전의 세부 동작을 단정하지 않고 짧게 끊어 하기와 화면 조절을 참고한다. https://www.stardewvalley.net/android-version-coming-soon/
- Factorio 개발자 FFF #412: 작업 결과 알림, 되돌릴 대상의 미리보기와 확인을 설명한다. 우리 게임에는 전체 시뮬레이션 되감기 대신 치명적인 선택 확인과 명확한 취소를 적용한다. https://www.factorio.com/blog/post/fff-412
- Game Accessibility Guidelines: 단순한 입력, 큰 간격, 정지한 선택 요소, 속도 조절, 현재 목표·도움말·자동/수동 저장을 권한다. https://gameaccessibilityguidelines.com/full-list/ https://gameaccessibilityguidelines.com/provide-an-autosave-feature/

## 구현 범위
1. 주인 버튼·목표·알림·작업 상태의 겹침을 해소하고 선택창과도 겹치지 않게 배치.
2. 우클릭 취소, 취소 시 지하 공사 모드·층 목적지까지 해제. 입력 후 연속 실행 방지.
3. 살해·석방·불러오기에 대상과 결과를 표시하고 확인. 일반 대화·이동에는 확인 없음.
4. 60초마다 별도 자동 저장, 수동 저장 분리, 이전 파일 백업과 임시 파일 교체. 자동 저장 이어하기 제공.
5. 화면을 떠나면 정지하고 저장. 복귀 시 사용자가 재개. 수동 정지와 대화 이전 정지 상태 보존.
6. 소리·경로 표시·확대·시점 방향을 기억. 마우스/핀치 외에도 설정에서 확대·축소.
7. 운영 현황에서 손님 요구·객실 사용 상태를 보고 바로 인물/객실 선택. 인물 선택 시 위치 강조.
8. 최근 알림 다시 보기와 짧은 조작 도움말. 실패 이유가 매출 알림에 가려지지 않게 처리.
9. 이동 경로와 도착 표시를 현재 보이는 층으로 제한. 기존 경로 표시를 확장.

## 범위 제한
실시간 시뮬레이션 전체 되감기, 모든 접근성 요구 충족, 모바일 실기기 체감 확인을 의미하지 않는다. 브라우저 저장은 해당 브라우저의 사이트 데이터에 보관되며 사이트 데이터를 지우면 사라질 수 있다. 현재 구조에서 안전하게 연결되는 편의 기능을 우선 적용한다.

## 완료 확인
편의성 집중 진단 25개와 변경 영향을 받는 층 이동 진단 15개를 통과했다. 실제 터치 이벤트의 층 버튼·사다리·계단, 상단 문구 영역 분리, 경로 표시 전환, 확인 취소, 연속 입력 제한, 설정 복원, 저장 파일 교체·백업 복구, 층 이동 중 저장 복구, 화면 이탈 정지, 시작 시 이어하기 제안을 포함한다. 자동 저장 간격은 게임 내 가속 시간과 별개로 활성 플레이 60초다.

찾는 곳: 주인 또는 설정 → 손님·객실 바로 찾기. 설정 → 조작·화면·소리 / 최근 알림 / 자동 저장 이어하기. 기존 주문·손님·경비 기능의 완성도를 새롭게 보증하는 것은 아니며 실제 휴대폰의 시각적·조작 체감은 미확인이다.
