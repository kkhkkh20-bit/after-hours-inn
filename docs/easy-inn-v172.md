# 1.7.2 쉬운 여관 운영·비밀 동선 기획

## 목표
첫 플레이에서 손님 선택 → 요구 확인 → 추천 방 안내만으로 매출이 발생하고, 18초 이상 기다린 일반 손님은 접수 직원이 맡는다. 주인이 지하에 있어도 식사·접수·청소가 순환한다. 초반 경제 압박보다 동선과 비밀 공간을 만지는 재미를 먼저 제공한다.

## 조사와 적용 판단
- Tavern Master 공식 개발사: 배치와 직원 역할을 갖추면 운영이 자동으로 돌아가는 구조. https://untitledstudio.dev/games/tavern-master
- Stardew Valley 모바일 조작 문서: 바닥 탭 이동, 대상 탭 접근·상호작용. https://stardewvalleywiki.com/Mobile_Controls
- Travellers Rest 직원 업데이트는 기존 1.7 조사에 연결한다. 이번 조회에서는 본문이 이미지로만 제공되어 세부 버튼 배치는 새로 확인했다고 주장하지 않는다.
- 아래 버튼 수·대기 시간·경제 지원·지도 색은 우리 게임을 위한 설계이며 원작 UI 복제나 정확한 원작 수치가 아니다.

## 조작 계약
1. 손님 클릭 즉시 요구를 읽는다. 숙박 손님은 첫 버튼 '추천 방 안내', 둘째 '직접 방 선택', 셋째 이야기, 넷째 다른 행동. 추천은 깨끗한 빈방 우선, 같은 층의 원한 관계와 거리가 먼 방 우선. 전부 청소 중이면 청소 후 예약 가능. 빈방 없음은 버튼 비활성화.
2. 쉬운 운영은 새 게임 기본값이다. 접수·청소·식사 직원 제공. 수동 배정 중인 손님은 직원이 가로채지 않는다. 일반 대기 손님은 18초 뒤 자동 접수하므로 먼저 말을 걸 시간도 있다.
3. 주인 메뉴에서 비밀 창고로 이동 → 입구 메뉴 → 내려가기가 된다. 식당과 지하 버튼은 시점만 바꾼다. 이동과 시점 변경을 혼동시키지 않는다.
4. 입구와 지하 시설은 최소 44 논리 픽셀 반경으로 선택한다. 입구 메뉴는 이동·덮개 상태·굴착·연결 선택을 제공한다.

## 맵 동선
- 손님: 마당 정문 → 식당/접수 → 객실 앞 공용 복도 → 1층 객실 또는 오른쪽 계단 → 2층 객실.
- 직원: 접수·주방·객실만 이동. 주인 창고와 지하를 순회하지 않는다.
- 주인: 식당 → 마당 쪽문 → 창고 앞 서비스 통로 → 주인 창고 → 지하. 뒷마당 우회로도 유지한다.
- 공용 복도는 따뜻한 바닥 띠, 창고 쪽 서비스 통로는 청록 바닥 띠로 표시한다. 띠는 장식이므로 길찾기 장애물을 만들지 않는다. 전투 회피 AI나 가구 자유 배치는 이번 범위가 아니다.

## 숨김과 난이도
- 쉬운 운영에서 입구를 통과하면 덮개를 자동으로 닫는다. 닫힌 입구도 주인은 보고 선택할 수 있다. 이는 플레이어의 관리 편의이며 벽 투시 감지가 아니다.
- 입구 메뉴에 실제 열림/숨김과 자동 닫힘 여부를 표시한다. 일반 공사 소음만으로 범죄 신고를 만들지 않는 기존 규칙 유지. 실제 범죄 목격과 실종 신고는 유지한다.
- 첫 3일 임대료·급여·미납 세금의 결산 청구 합계는 최대 6닢. 자발적으로 낸 세금은 되돌리지 않는다. 4일차부터 원래 경제로 복귀한다. 시작 지원을 끄면 기존 비용과 접수 대기 규칙 적용. 이미 고용한 직원은 해고하지 않는다.
- 첫 2일 손님 세력 다툼을 유예해 운영부터 익힌다. 범죄를 무조건 무사 통과시키지는 않는다.
- 기존 저장은 자동으로 설정을 바꾸지 않는다. 설정에서 쉬운 운영을 켜면 무료 직원 지원 적용. 별도 회원가입·에셋 구매 없음.

## 완료 기준
추천→예약→숙박 수금, 자동 접수 예약 충돌 방지, 기존 수동 조작, 덮개 자동 닫힘과 직접 열기, 결산 지원 전후 값, 실제 공용·서비스 통로 경로를 좁은 조건으로 확인한다. 실기기 터치와 긴 플레이의 재미는 확인 한계로 기록한다.

## 구현 기록
기획 항목을 3D 프로젝트에 적용했다. 새 시작 시 이전 객실·시계·주문 상태가 남던 초기화도 수정했다. 집중 조건 41/41 통과: 기존 수동 예약·입력·취소 30개와 직원 지원, 초반/4일차 비용, 추천 객실·예약, 자동 접수 대기, 덮개 왕복, 실제 서비스 통로 및 손님 창고 진입 차단을 확인했다. 모바일 실기기·장시간 운영 밸런스는 미확인이다.
