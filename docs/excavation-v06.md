# 0.6 — 사용자 플레이에서 막힌 진입·굴착과 이동 공간 수정

흙벽을 정확히 옆칸에서 클릭해야만 작동하던 조작을 자동 접근 후 직접 굴착으로 바꿨다. 클릭 이벤트의 좌표를 즉시 광선 투영해 이전 프레임 마우스 위치에 의존하지 않는다. 출입구 버튼과 Q는 실제 길을 걸어 입구를 열고 층을 바꾼다. E로 가까운 벽도 팔 수 있다.

기본 지급 곡괭이·삽을 손에 표시하고 작업 중 움직임·진행률을 보인다. 내구도 24, 시작한 작업당 1 소모, 접수대 T로 2닢 수리. 자동 이동 중에는 비용·내구도 소비 없이 취소할 수 있다. 도구·접근 경로·진행 작업·입구 개방 상태를 저장한다.

실내 바닥을 20×12로 넓히고 지상 이동 범위를 28×16으로 확장했다. 가구를 서쪽으로 옮겨 중앙 통로를 넓혔고 앞쪽 출입구를 열었다. 카메라는 지상에서도 주인을 따라간다. 지하 시작은 5×5, 기존 저장의 열린 칸을 보존하며 시작 영역을 추가한다. I로 양옆 정보 패널을 접는다.
