# 1.7.8 층 이동 통일

문제: 사다리 발밑 44px만 인식하고, 2층에서 계단 선택이 누락되어 있었다. 층 버튼은 시점만 바꿔서 주인은 다른 층에 남았다. 메뉴 경유 이동은 작업 취소·추적 전환과 분리되어 있었다.

반영:
- 사다리의 발밑부터 몸통까지와 입구 이름을 이동 대상으로 받는다. 실제 인물 몸을 정확히 누른 경우는 인물 선택을 유지한다. 주인이 사다리를 가리는 경우는 사다리 이동을 우선한다.
- 계단 경사면은 1층·2층 양쪽에서 이동 대상으로 받는다. 한 번 누르면 접근과 오르내리기를 이어간다.
- 상단 1층·2층·지하는 화면 탐색 대신 실제 이동 목적지다. 전체 버튼은 관찰용으로 유지한다. 현재 층 버튼은 주인 위치로 돌아간다.
- 지하에서 2층, 2층에서 지하는 1층을 거쳐 자동 이동한다. 도착 시 카메라는 주인 층과 위치를 따른다.
- 이동 목적지를 표시하고 취소·다른 바닥 이동·새 게임은 기존 목적지를 해제한다. 일시정지는 자동으로 풀지 않는다.
- 기존 입구 덮개·공사 메뉴는 유지한다. 직접 입구 클릭은 이동이 기본이다.

확인: 실제 터치 이벤트로 2층 버튼, 계단 내려가기, 사다리 몸통 올라가기와 목적지 도착을 확인했다. 두 구간 이동, 취소, 일시정지를 포함한 15개 집중 진단 통과. 실제 휴대폰에서의 조작감은 미확인이다.
