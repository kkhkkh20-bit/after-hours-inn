# 0.7 — 세로 화면과 포인터 중심 UI

720×1280을 기본으로 상단 상태·중앙 월드·하단 상황 행동·영업/관리/의뢰/메뉴 창을 구성했다. UI는 별도 mobile_ui.gd로 분리하고 화면 요소를 앵커와 컨테이너로 배치한다. 가로로 넓은 화면에서는 720 폭의 UI를 중앙에 둔다.

바닥 탭 경로 이동과 화면 끌기, 확대/축소, 주인 위치 복귀를 구현했다. 손님 선택과 상황 버튼, 직원/의뢰/영업 명령은 실제 접근 후 기존 행동 검증을 거친다. 직접 공간에 가지 않고 돈이나 상태를 원격 변경하지 않는다.

터치→에뮬레이트된 마우스의 중복 월드 동작을 막고, 정보창에서 시작한 입력은 창이 닫혀도 바닥으로 통과시키지 않는다. 터치 드래그도 이동 탭과 분리한다. 저장에 이동 중인 명령과 대상을 포함하며 이전 저장과 호환한다.

120개 시뮬레이션과 30개 실제 포인터/터치 입력 검증 통과. 720×1280 창에서 GUI 입력을 보내 일반 영업과 비밀 의뢰 흐름을 키보드 없이 검증했다. v07-surface.png, v07-service.png, v07-excavation.png는 실제 Godot 렌더링 캡처다. 실제 휴대폰 브라우저의 터치감과 주소창·안전 영역·성능은 별도 확인이 필요하다.
