# 1.7.7 주인 중심 시점과 선택

문제: 전체 지도 기본 화면과 이동 후 유지되는 관찰 오프셋 때문에 주인을 놓치기 쉬웠다. 인물 주변 48px 선택 영역과 넓은 이름 영역은 바닥 이동을 가로챘다.

반영:
- 새 게임은 현재 층에서 주인 추적, 기본 화면 폭 24로 시작한다.
- 상단 주인 버튼에 현재 층과 추적 상태를 표시하고 한 번 눌러 시점·오프셋·층을 되돌린다. 기존 저장도 이 버튼으로 적용할 수 있다.
- 주인 위 밝은 표식과 발밑 원형 표시를 추가한다. 표식은 가구 뒤에서도 보인다.
- 드래그하면 화면의 현재 위치를 유지한 채 자유 관찰로 전환한다. 바닥에 유효한 이동 명령을 주면 주인 추적을 재개한다.
- 인물 몸을 직접 누른 선택이 이름·주변 영역보다 우선한다. 마우스는 몸과 작은 이름 영역만, 터치는 28px의 보조 영역을 허용한다. 실제로 겹친 몸은 대상 목록을 유지한다.
- 누르고 있는 동안과 선택창이 열려 있는 동안 추적 카메라를 고정해 누르는 중 대상이 카메라 때문에 이동하지 않게 한다.
- 현재 층 변화는 추적 시 해당 층을 따라간다. 전체·구역 보기는 기존 상단 버튼으로 남긴다.

확인: 변경 흐름 14개 집중 진단 통과. 실제 터치 입력을 통한 주인 찾기, 바닥 명령의 추적 재개, 관찰 시점 유지, 층별 좌표, 인물 주변 빈 바닥 판정을 포함한다. 모바일 실기기 체감은 미확인이다.
