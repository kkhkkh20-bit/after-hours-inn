# 1.7.3 즉시 놀 수 있는 여관·지하

## 조작
- 흙벽 한 번 클릭 → 옆으로 이동 → 곡괭이 작업 한 번 → 정확히 한 칸 추가. 기존 연속 통로 계획은 별도 구멍·통로 파기 메뉴에 유지한다.
- 지하에서 주인 클릭 → 지하 시설 설치 → 감옥/은닉 창고/은신처/화로 → 열린 바닥 지정 → 이동·공사.
- 시작 자금 300닢. 기존 저장도 최초 한 번 300닢 미만이면 지원하며, 이후에는 반복 보충하지 않는다.
- 지하의 네 시설을 무료로 하나씩 제공하고 창고 입구·각 시설·객실 통로 출구를 연결한다. 이미 같은 시설을 보유했다면 중복 생성하지 않는다.

## 손님
- 마당 정문 → 바깥 앞마당 → 여관 정문 → 목적지로 들어온다. 쪽문을 통과해 들어오는 최단 경로를 사용하지 않는다.
- 식사 손님은 네 테이블 좌석 중 빈 자리로 이동해 앉아 주문 대기 → 직원 조리·서빙 → 식사 → 퇴장한다. 숙박 대기 줄과 테이블 예약은 분리한다.
- 숙박 손님은 카운터 앞 최대 세 대기 위치를 쓴다. 전 객실이 사용/예약 중이면 접수 직원이 만실을 알리고 정문으로 돌려보낸다. 청소만 남은 방은 직원이 정리할 때까지 대기할 수 있다.

## 객실 비밀 통로
- 다섯 객실에 덮개와 지하 연결 통로를 기본 제공한다. 객실 안 시신을 클릭하거나 해당 객실 메뉴에서 비밀 통로 이동을 선택한다.
- 주인이 해당 층으로 이동한 뒤 가까이 접근해야 작동한다. 통로 출구로 옮기는 게임 기능이며 시신을 삭제하지 않는다. 지하에서 다시 끌어 화로로 운반할 수 있다.
- 실제 목격과 기존 실종 신고는 남는다. 통로를 썼다는 이유로 신고 기록을 지우지 않는다. 살아 있는 손님을 즉시 투입하는 기능은 없다.

## 외부 바닥
지하를 보여주는 전체 시점에서 넓은 지상 바닥을 그대로 켜면 지하가 가려진다. 건물 밖 주인 발밑에 작은 지상 바닥을 표시해 층과 위치를 알 수 있게 했다. 식당 시점에서는 기존 넓은 마당 바닥을 유지한다. 정문 발판과 정문 안내도 추가했다.

## 적용 범위
새 게임과 기존 저장의 첫 실행에 기본 시설·지원금을 한 번 적용한다. 직접 만든 지하 시설과 자금이 300닢보다 많을 때의 잔액은 유지한다. 모바일 실기기 조작감과 장시간 경제 밸런스는 미확인이다.

집중 확인: 59/59 조건 통과. 한 칸 굴착, 네 시설 연결, 정문 경유, 식사 주문·서빙·퇴장, 만실 퇴장, 시신 지하 이동, 시설 추가 공사와 비용을 확인했다.
