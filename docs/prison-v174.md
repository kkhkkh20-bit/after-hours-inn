# 1.7.4 쉬운 수감·감옥 생활

## 클릭 규칙
이름과 머리 부분도 인물 선택 영역에 포함한다. 빈 곳을 눌러 선택창을 닫은 뒤 다시 눌러 이동하는 두 번 조작을 없애고, 한 번에 닫기와 이동을 처리한다. 확장 선택 영역이 겹쳐도 거리가 충분히 다르면 가까운 인물을 바로 고르고, 실제로 붙어 있는 인물만 이름 목록으로 구분한다. 대상을 선택하는 것만으로 진행 중인 작업을 취소하지 않는다.

## 수감 흐름
일반 인물의 기본 선택에 '감옥에 가두기'를 둔다. 빈 감옥을 자동 선택하고 주인이 대상에게 접근 → 붙잡기 → 계단/입구를 통해 호송 → 수감한다. 순간 이동이나 대상 클릭만으로 수감하는 방식은 아니다. 작업 표시는 현재 호송 중임을 보여주고 취소 시 대상은 현재 위치에서 잠시 쓰러진 상태가 된다. 시신은 수감 대상이 아니며 기존 객실 비밀 통로를 쓴다. 기본 수용 6명, 추가 감옥과 12명까지의 증설을 지원한다.

## 생활 시뮬레이션
각 수감자에게 배고픔·기력·기분·생활 행동·다음 탈출 시각·시도 횟수를 저장한다. 수감 상태를 유지한 채 감옥 안에서 배회·식사·대화·휴식·수면한다. 돌봄을 켜면 식사와 휴식이 자동으로 돌아간다. 굶주림이나 피로로 즉시 죽지는 않는다. 낮은 기분에서는 다툼·문을 살피는 행동이 생긴다.

## 쉬운 경비
새 감옥은 자동 돌봄·잠금·경비가 켜진다. 기본 경비 수치는 99/100이며 불만이 크거나 탈출 성향인 수감자가 일정 간격으로 탈출을 시도한다. 실패하면 경비가 붙잡고 생활로 복귀한다. 실제 탈출은 지하 출구로 이동하는 기존 도주 경로를 사용한다. 경비와 잠금을 해제하면 위험이 크게 오른다. 자동 돌봄과 경비는 이번 버전에서 추가 유지비 없이 제공한다.

## UI
감옥 클릭: 수용 인원·보안·자동 돌봄·최근 상황을 표시한다. 수감자 목록, 자동 돌봄 전환, 경비/잠금 전환, 증설을 제공한다. 수감자 클릭: 이름·생활 상태·세 수치와 식사·휴식·석방을 제공한다. 감옥 화면을 열어도 시뮬레이션은 계속 흐르며 상태 문구가 갱신된다. 타이쿤식 관찰 방향을 반영한 자체 설계이며 특정 게임의 시스템을 그대로 복제한 것은 아니다.

## 범위와 한계
식사·수면·배회·갈등·탈출 시도·자동 호송이 이번 범위다. 독립된 경비 직업 AI, 재판·형량, 정교한 집단 폭동·직업 생산은 포함하지 않는다. 모바일 실기기의 체감과 장시간 균형은 별도 확인이 필요하다.

## 구현 기록
75/75 집중 조건 통과. 자동 접근·붙잡기·지하 호송·수감, 다인 수용, 생활 행동 순환, 식사·증설·저장 복원, 경비의 탈출 저지 및 무경비 상태의 실제 도주 경로, 실시간 상태창, 간판 선택, 호송 취소, 한 번의 바닥 탭 이동을 확인했다. 경비 모델의 순찰 연출은 보안 수치의 시각 표현이며 독립된 경비 AI로 주장하지 않는다.

배포 캐시: Web 내보내기 파일은 커밋별 고유 이름으로 생성하고 진입 HTML만 index.html로 제공한다. HTML의 버전 쿼리가 바뀌면 이전 JS·WASM·PCK 파일 이름을 재사용하지 않는다. Windows 저장과 내보내기는 유지한다.
