# 0.4 잠입 기초 구현

## 범위
직원 한 명의 청취, 100도 전방 시야, 실제 격자 경로 접근, 6초 확인, 작업 지속 확인 시 20초 업무 거부와 영속 기억. 손님 지각·구금·전투·세력·조사관은 미구현.

## 선택과 결과
빠른 굴착 4초 / 조용한 굴착 10초. 같은 비용 1닢. 작업 중단 시 지형은 열리지 않고 도구 비용은 돌아오지 않는다. 소음은 즉시 사라지지 않고 감소한다. 직원은 현재 소유한 식사 주문을 완료하고 조사하므로 이중 소유나 중복 지급이 없다. 접근·확인 중에는 새 주문을 받지 않는다.

귀로 들은 의심과 실제 확인 기억을 분리한다. 조용해지면 확인을 마치고 돌아간다. 시야 내 근거리 E로 설명할 수 있으나 확인한 기억은 지우지 못하고 재사용 간격이 있다. 계단을 사용하는 모습이 시야에 잡히면 작은 의심이 추가되지만 그 자체로 범죄로 취급하지 않는다.

## 구현과 검증
simulation.gd가 모든 상태와 저장 원본을 소유한다. 시야선은 충돌과 같은 벽·가구 경계를 사용한다. 소리는 먼저 지하에서 계단까지, 이어 위층 길찾기 경로로 감쇠한다. 여러 문·층의 완성 음향 모델은 아니다. main.gd의 원뿔은 같은 시야 끝점 함수를 시각화한다.

61개 시뮬레이션 + 13개 입력 검증: 영업 회귀, 소음 유인, 직원 접근, 중단 회피, 지속 작업 확인, 기억 보존, 설명 반복 제한, 조용한 굴착 시간/소음, 거리/깊이 감쇠, 방향과 벽 가림, 조사 중 저장, 0.3 저장 이전, 주문 소유 완료, R/X/V/M 입력.

실제 실행 캡처: v04-surface.png, v04-stealth.png. UI와 지하 작업 상태를 확인했다. 사용자의 브라우저 재미 평가는 별도다.
