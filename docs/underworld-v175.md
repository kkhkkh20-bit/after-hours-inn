# 1.7.5 넓은 비밀 여관과 표적 의뢰

## 맵
지상 이동 범위를 38×20에서 72×48로 넓힌다. 중앙 여관은 기존 길찾기와 객실을 보존하고 서쪽에 연결 식당 홀을 붙인다. 기존 지하를 보존하면서 서쪽 수감 구역·중앙 심문 구역·동쪽 보안 구역·남쪽 확장 구역을 연결한다. 지하 굴착 범위는 77×45에서 129×81로 넓힌다. 넓어진 지도는 드래그·확대 축소와 구역 바로 보기를 지원한다. 면적은 논리 좌표 기준이며 건물 전체를 같은 비율로 키우는 변경이 아니다.

## 목적
여관에서 범죄자 정보를 확인 → 표적 의뢰 수락 → 실제 손님으로 도착한 표적 관찰 → 생포/수감 또는 지정 표적 암살 → 수감 후 정보·불법 자금 확보 → 게시판에서 보상 수령 → 다음 사건. 세 사건을 한 묶음으로 반복한다. 다른 일반 손님을 가둬도 지정 의뢰가 완료되지는 않는다.

1. 가짜 징수관: 피난민을 갈취한 정황 확인, 생포 후 정보 확보.
2. 인질 장사꾼: 인신 매매 장부 정황 확인, 생포 후 자금 회수.
3. 매복대 지휘관: 범죄 확인 후 암살하거나, 생포해 정보를 얻는 두 방식 중 선택.

## 수감자 선택
일반 심문은 시간이 들지만 신뢰할 수 있는 진술을 얻는다. 금품 갈취는 대상마다 한 번만 가능하며 원한과 추적 위험이 오른다. 강압/고문 심문은 추상적인 수치와 문구로 처리하며, 잔혹한 시각 묘사나 실제 방법은 없다. 진술 진척은 빠르지만 기분·추적 위험·신뢰도에 불이익이 생긴다. 불확실한 정보는 대조해야 의뢰의 정보 조건을 충족한다.

## 조작과 진행 표시
접수대/주인에서 현상수배 게시판을 바로 연다. 게시판에는 표적 이름·혐의·완료 조건·보상·현재 상태를 표시한다. 수감자에는 심문·금품 갈취·강압 심문·정보 대조 메뉴를 추가한다. 보상은 사건당 한 번 지급한다. 화면 목표는 현재 사건의 다음 행동을 가리킨다. 아직 수락하지 않은 표적은 자동 생성하지 않는다.

## 기존 저장
기존 지하·시설을 지우지 않고 새 구역과 감옥을 한 번만 추가한다. 새 의뢰 상태와 진술·금품 수령 여부는 저장에 포함한다. 기존 임대료·수감 생활·원클릭 호송을 유지한다.

## 범위
심문은 원격 관리 UI의 추상적 처리이며 인물을 심문 의자로 실제 이동시키는 별도 연출은 포함하지 않는다. 표적 세 명은 수작업으로 작성한 허구의 인물이고, 실제 사람에 대한 판정 시스템이 아니다.

## 구현 기록
89/89 집중 조건 통과. 지상 외곽·서쪽 식당 이동, 지하 네 구역 연결, 확장 중복 방지, 실제 표적 입장, 정보 의뢰 완료, 보상·금품 중복 방지, 암살 조건, 의뢰 저장 복원, 강압 진술의 대조 필요, 추적 위험으로 실제 조사 예약을 확인했다. 큰 지하의 길찾기는 굴착/복원 시만 지도를 갱신하는 캐시로 바꿨다. 실기기 터치 및 장시간 밸런스는 미확인이다.
