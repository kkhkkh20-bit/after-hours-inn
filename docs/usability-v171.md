# 1.7.1 조작 개선

기존 3D 운영 흐름에서 확인된 문제를 수정했다.

- 도달 불가능한 바닥을 눌러도 진행 중인 예약·안내·작업을 유지한다. 새 경로가 존재할 때만 이전 작업을 취소하고 예약을 해제한다.
- Windows에서 Esc를 눌러도 종료하지 않는다. 선택창 닫기 → 공사 위치 선택 해제 → 설정 열기 순서로 처리한다. 웹도 같은 규칙을 쓴다.
- 식당·객실·지하·전체 중 현재 화면 버튼을 색으로 구분한다. 선택창을 열어도 표시를 유지한다.
- 경로 길이와 종점이 같아도 중간 경로가 달라지면 선을 갱신한다. 주인이 이동하면 남은 경로에 맞춰 선의 시작점도 갱신한다.

기존 25개 조건과 추가 5개 조건을 Godot에서 실행해 30/30 통과했다. 모바일 실기기 조작감과 장시간 운영 밸런스의 완료를 의미하지 않는다.
