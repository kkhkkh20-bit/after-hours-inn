문 닫은 뒤 — OpenClonk 전체 원본 기반 시나리오 0.1

PC 시제품입니다. 모바일/브라우저용 게임이 아닙니다. 게임 화면은 현재 영어입니다.

전체 Windows 패키지: 압축을 풀고 START-INN.cmd를 실행하세요.
작은 시나리오 ZIP: OpenClonk 8.1을 먼저 설치한 뒤 START-INN.cmd를 실행하세요.
설정/세이브 경로는 기존 OpenClonk와 구분됩니다.

플레이: A/D 이동, W 점프/사다리 오르기, S 내려오기.
1 삽, 2 망치, 3 곡괭이, 4 도끼, 5 랜턴. 마우스로 도구를 사용합니다.
손님/Mara를 클릭하면 원본 대화 창에서 요청/접객/고용/보급/월세를 선택합니다.
식사 12, 객실 35, 직원 고용 30, 음식 10개 10, 하루 월세 120.
첫 소지금 500. 위층 객실 5개, 지상 주방과 보급함, 아래 창고·제련소·연구실.
첫 지하 입구와 마당 입구는 해치로 덮여 있습니다. 가까이 가서 E 또는 상호작용으로 여세요.
삽은 흙, 곡괭이는 돌을 팝니다. 망치는 원본 건설 메뉴/미리보기를 사용합니다.
구조물은 원본의 재료·접근·지형 조건을 따릅니다. 시제품에서 즉시 무료 설치로 바꾸지 않았습니다.
하루 약 3분, 객실 약 65초 후 해제. 직원 고용 후 자동 접객을 맡기고 지하를 확장할 수 있습니다.

현재 한계: 숙박은 객실 점유와 NPC 이동 수준이며 침대/수면 연출은 없습니다.
감옥 운영, 포로 AI, 암살·시체 운반·세력·의심 시스템은 이번 시나리오에 없습니다.
가족 단위 예약, 모바일 터치 이동, 한글 UI, 완성 미술도 미구현입니다.
Windows 패키지는 공식 실행 파일을 묶었습니다. 실제 플레이와 스크린샷은 Linux 8.1에서 확인했습니다.
Windows 기기에서의 실행 성공을 별도 확인한 것은 아닙니다.
