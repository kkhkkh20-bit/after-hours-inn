# 문 닫은 뒤 — 탑다운 여관 v0.1

Restaurant for Monsters의 MIT 소스와 생성 에셋을 가져온 별도 Godot 프로젝트입니다. 기존 3D 및 단면 버전의 파일과 저장 데이터는 변경하지 않습니다.

## 실행
원본 에셋 생성기를 포함합니다. 저장소에서는 큰 생성 결과물을 중복 보관하지 않고 아래 명령으로 복원합니다.

```bash
python -m pip install -r requirements-assets.txt
python tools/build_assets.py
```

한국어 글꼴은 상위 프로젝트 assets/fonts/InnKorean.otf를 assets/ui/font/InnKorean.otf로 복사합니다. OFL.txt도 함께 복사합니다. 이후 Godot 4.7.2에서 project.godot를 열어 실행합니다. GitHub Actions에서는 복원과 내보내기를 자동으로 수행합니다.

## 조작
- 빈 바닥 클릭: 가구를 피해 이동. 새 지점을 누르면 현재 주인 작업을 취소하고 이동합니다.
- 손님 클릭 → 말 걸기 → 주문 요리/객실 안내. 요리부터 서빙까지 자동으로 이어집니다.
- 위쪽 게시판: 직원 최대 3명 고용(45G, 하루 임금 12G). 직원은 주문에 맞춰 이동·요리·서빙합니다.
- 주방/바: 식재료 20인분 구매(16G).
- 오른쪽 아래 접수대: 직원의 방 안내 자동화 설정. 직원이 있으면 퇴실 청소도 자동 진행합니다.
- 계단 또는 상단 층 표시: 식당/객실 전환. 객실은 2인실 3개와 4인실 2개입니다.
- 아래쪽 빈 식탁 자리: 65G로 확장. 기본 4개에서 최대 6개 테이블.
- 하루 약 2분. 마감 후 정산에서 다음 날을 엽니다. 1배/2배와 일시정지 지원.
- 전용 저장 경로와 자동 저장. 진행 중인 식당 방문객 자체는 재구성되며, 돈·재고·객실·직원·시간·일일 매출은 유지합니다.

## 범위
첫 운영 버전입니다. 원본에서 가져온 접객 상태 머신, 만족도·결제·관계 계산, 애니메이션·음향·에셋 생성기를 사용합니다. 세로 화면, 경로 이동, 사람 손님·일행, 숙박, 직원, 식재료 구입과 식당 확장은 이번 포크에 추가했습니다.

손님 몸체는 원본 요리사 스프라이트를 색상별로 재사용하는 임시 아트입니다. Travellers Rest 수준의 아트, 주방 직원의 도구 애니메이션, 객실까지 계단을 실제 오르는 이동, 지하·세력·비밀 행동은 아직 구현하지 않았습니다. 첫 버전은 여관 운영 방향을 잡는 데 집중합니다.
